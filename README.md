# genai-class-notebooks
Generative AI engineering notebooks (LangChain-based) — covering LLM fundamentals &amp; sampling parameters, prompt engineering, tokenization, chat models &amp; message types, multimodal inputs (image, audio, PDF, video), structured output, embeddings &amp; semantic similarity, document loaders &amp; chunking strategies, vector stores, retrievers &amp; RAG pipelines. 

## Note on sample data
Some multimodal notebooks (image, audio, PDF input notebooks) expect local sample 
files as input — these are excluded from the repo for privacy reasons. Replace the 
file paths in the notebook cells with your own sample images/documents to run them.

## Setup
1. Install dependencies: `pip install -r requirements.txt` (or `uv sync` if using uv)
2. Add your API keys to a `.env` file
3. Run notebooks in Jupyter or VS Code
